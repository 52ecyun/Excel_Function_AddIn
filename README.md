# E+ AI 函数库｜Excel/WPS 专业扩展函数库
官网：**calcx.cn**

## 🌟 产品简介
E+ AI函数库（灵析表格出品），面向Excel、WPS打造的专业表格扩展函数插件。一键安装即可加载数百枚增强函数，调用方式与软件原生函数完全一致，补齐表格内置函数短板，无需VBA、不用编写代码，直接在单元格内通过公式实现复杂数据处理，为传统表格赋能AI智能能力。

## 🚀 核心优势
- **一键安装部署**：可视化安装工具，向导式配置，无需复杂环境设置，重启表格软件立即生效
- **双平台完美兼容**：全面适配Microsoft Excel、WPS Office，支持32/64位Windows客户端
- **函数中英双语调用**：全部函数配套中文名称、英文名称两套写法，适配不同使用习惯
- **离线+在线双模式**：基础数据函数本地运行无需联网；AI系列函数支持云端智能运算
- **零学习成本**：沿用`=`开头标准公式写法，上手门槛低，职场人员快速复用

## 🔧 安装指南
1. 访问官网 **calcx.cn** 下载最新版【Excel公式盒子】安装包
2. 运行安装程序，根据向导选择对应Office/WPS版本完成部署
3. 关闭并重新启动Excel / WPS表格，即可直接使用全部扩展函数

## 📌 使用重要说明
1. **AI系列函数**：需要网络连接进行接口调用
2. **通用增强函数**：本地离线运算，不消耗网络、无数据上传
3. **调用规范**：和原生函数一致，单元格以 `=` 开头直接输入函数名称使用
